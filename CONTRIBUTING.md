# Cómo contribuir

1. Crea una rama a partir de `main`.
2. Instala dependencias con `npm ci` y ejecuta `npm test` antes de abrir un pull request; todas las pruebas deben pasar.
3. Los textos visibles para el usuario van en español (Latinoamérica), tuteando.
4. No agregues fuentes de descarga, espejos ni servicios de terceros sin explicarlo en el pull request.
5. Las descargas que se ejecutan o instalan deben verificarse (SHA-256 o la suma que publique la fuente oficial).
